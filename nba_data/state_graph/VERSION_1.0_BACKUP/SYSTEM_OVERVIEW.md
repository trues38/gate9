# NBA 베팅 분석 시스템 완성본

## 시스템 구성

```
┌────────────────────────────────────────────────────────────────┐
│                  NBA 베팅 분석 시스템                          │
│                                                                │
│  데이터: 2시즌 (2,249경기)                                     │
│  기간: 2023-10-24 ~ 2025-12-24                                │
│  분석: 역사적 패턴 + 최신 트렌드                               │
└────────────────────────────────────────────────────────────────┘
```

## 3가지 분석 레이어

### 1️⃣ 역사적 패턴 분석 (context_based_analysis.py)

**2,249경기 데이터 기반 구조적 패턴**

```
✅ 휴식일별 패턴
  - "BOS 백투백 홈: 87.5% (14승 2패)"
  - "ORL 1일 휴식 홈: 83.3% (35승 7패)"
  - "CLE 1일 휴식 홈: 73.5% (36승 13패)"

✅ 백투백 효과
  - 강팀은 백투백에도 강함
  - 약팀은 백투백에 더 취약

✅ 부상자 영향
  - 4명 이상 부상 시 승률 6-9% 하락

✅ 심판 편향
  - 홈 유리 심판 vs 중립 심판

✅ 휴식일 우위
  - 2일 이상 차이 시 유의미
```

### 2️⃣ 최근 트렌드 분석 (recent_form_analysis.py) 🔥 NEW!

**최근 5-10경기 기반 현재 폼**

```
✅ 최근 5경기 폼
  - "BOS: WWWLL (3승 2패, 60%)"
  - "IND: LLLLL (0승 5패, 0%)"

✅ 연승/연패 Streak
  - 🔥 "BOS: 3연승"
  - ❄️ "IND: 6연패"

✅ 득점 트렌드
  - "CHI 최근 5경기: 평균 129점 (시즌 대비 +10.4점) 🔥"
  - "UTAH 수비: 평균 135점 실점 (시즌 대비 +11.7점) ❄️"

✅ 홈/원정 최근 성적
  - "BOS 최근 원정: 80% (4승 1패, 평균 +11.2점)"
  - "IND 최근 홈: 20% (1승 4패, 평균 -8.2점)"

✅ 최근 맞대결
  - "최근 3경기: BOS 2승 - 1승 IND"

✅ 모멘텀 지표 (0-100)
  - BOS: 79 vs IND: 0 (79점 차!)
  - DET: 89 vs UTAH: 18 (71점 차!)
```

### 3️⃣ ESPN 프리뷰 통합 (analyze_with_preview.py)

```
✅ ESPN 예측 승률
✅ 부상자 명단 (실시간)
✅ 심판 정보 (경기 4-6시간 전)
✅ 배당 정보 (API 변경으로 현재 미제공)
```

## 핵심 강점

### 1. 역사적 패턴 × 최신 트렌드 조합

```
예시: BOS @ IND

역사적 패턴:
  ✅ BOS 원정 3일 휴식: 78% 승률 (역사적 강세)
  ✅ IND 홈 2일 휴식: 33% 승률 (역사적 약세)

최신 트렌드:
  ✅ BOS: 3연승, 최근 원정 80% (4승 1패)
  ❌ IND: 6연패, 최근 홈 20% (1승 4패)
  ✅ 모멘텀: BOS 79 vs IND 0

결론: BOS 압도적 유리! (컨버전스)
```

### 2. 통계적 신뢰도

```
샘플 사이즈:
  - 2시즌 2,249경기
  - 신뢰 가능 패턴: 70개 (20경기 이상)
  - 양호 패턴: 103개 (10-19경기)

→ 전체의 54%가 통계적으로 신뢰 가능!
```

### 3. 최신성 유지

```
자동 업데이트:
  - 매일 어제 경기 추가
  - 패턴 실시간 재계산
  - 2년 이내 데이터만 유지

→ 항상 최신 트렌드 반영!
```

## 일일 사용법

### 한 줄 명령어

```bash
./daily_betting_report.sh
```

### 실행 과정 (자동, 약 30초)

```
Step 0: 어제 경기 결과 업데이트 (최신 패턴 유지)
Step 1: 내일 경기 스케줄 가져오기
Step 2: ESPN 프리뷰 정보 수집
Step 3: 경기 컨텍스트 계산 (휴식일, 부상자, 백투백)
Step 4: 역사적 패턴 기반 예측 생성
Step 5: 최근 트렌드 분석 (폼, 연승, 득점)
Step 6: 통합 보고서 생성
```

### 생성되는 3가지 보고서

```
1. context_based_analysis_YYYYMMDD_HHMM.txt
   → 역사적 패턴 (휴식일, 백투백, 부상자, 심판)

2. recent_trends_YYYYMMDD_HHMM.txt
   → 최근 트렌드 (폼, 연승, 득점, 모멘텀)

3. enhanced_analysis_YYYYMMDD_HHMM.txt
   → ESPN 예측 + 역사적 패턴 통합
```

## 베팅 활용 예시

### Case 1: BOS @ IND (2025-12-27)

**역사적 패턴:**
- IND 홈 2일 휴식: 33.3% 승률 (3경기)
- IND 부상자 5명 → -9% 페널티
- 예측: IND 41%, BOS 59%

**최근 트렌드:**
- IND: 6연패! (최근 5경기 0승 5패)
- BOS: 3연승 (최근 5경기 3승 2패)
- BOS 최근 원정: 80% (평균 +11.2점)
- IND 최근 홈: 20% (평균 -8.2점)
- 모멘텀: BOS 79 vs IND 0 (79점 차!)

**베팅 판단:**
```
✅ BOS 머니라인: 강력 추천
✅ BOS 스프레드 -3.5: 추천 (최근 원정 +11.2점)
⚠️  오버 225.5: 보류 (IND 최근 공격 12점 하락)
```

### Case 2: DET @ UTAH (2025-12-27)

**역사적 패턴:**
- UTAH 홈 2일 휴식: 33.3% 승률 (9경기)
- UTAH 부상자 4명 → -6% 페널티
- 예측: UTAH 44%, DET 56%

**최근 트렌드:**
- DET: 3연승 (최근 5경기 4승 1패, 80%)
- UTAH: 4연패 (최근 5경기 1승 4패, 20%)
- DET 최근 원정: 60% (평균 +3.6점)
- UTAH 최근 홈: 20% (평균 -8.2점)
- 모멘텀: DET 89 vs UTAH 18 (71점 차!)

**베팅 판단:**
```
✅ DET 머니라인: 강력 추천
✅ DET 스프레드: 추천
⚠️  오버언더: UTAH 최근 득점 +13점 BUT 실점 +12점 → 오버 가능성
```

### Case 3: CHI vs PHI (흥미로운 역설)

**역사적 패턴:**
- CHI 홈 2일 휴식: 66.7% 승률
- PHI 원정 2일 휴식: 71.4% 승률
- 예측: CHI 59%, PHI 41%

**최근 트렌드:**
- CHI: 4연승! (평균 129점, 시즌 대비 +10.4점)
- PHI: 1연패
- BUT PHI 최근 원정: 80% (4승 1패, 평균 +8.4점)
- CHI 최근 홈: 20% (1승 4패)
- 모멘텀: CHI 77 vs PHI 57

**베팅 판단:**
```
⚠️  매우 흥미로운 경기!
  역사 + 트렌드: CHI 유리
  BUT PHI 최근 원정 폼 매우 좋음

→ 스킵 또는 라이브 베팅 추천
```
