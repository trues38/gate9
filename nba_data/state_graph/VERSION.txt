NBA 베팅 분석 시스템 버전 관리
================================================================================

VERSION 1.0 - STABLE BASELINE (2025-12-25)
================================================================================

시스템 구성:
------------
✅ 데이터: 2시즌 (2,249경기)
  - 2023-24 시즌: 1,322경기
  - 2024-25 시즌: 927경기
  - 기간: 2023-10-24 ~ 2025-12-24

✅ 3가지 분석 레이어:
  1. 역사적 패턴 분석 (context_based_analysis.py)
     - 휴식일별 승률 (2,249경기 기반)
     - 백투백 효과
     - 부상자 영향 (4명 이상 -6~9%)
     - 심판 편향
     - 휴식일 우위

  2. 최근 트렌드 분석 (recent_form_analysis.py)
     - 최근 5경기 폼 (WWLWW 패턴)
     - 연승/연패 스트릭
     - 득점 트렌드 (최근 vs 시즌 평균)
     - 홈/원정 최근 성적
     - 모멘텀 지표 (0-100)

  3. ESPN 프리뷰 통합 (analyze_with_preview.py)
     - ESPN 예측 승률
     - 부상자 명단
     - 심판 정보
     - 배당 정보

✅ 자동화:
  - daily_betting_report.sh (한 줄 실행)
  - update_yesterday_games.py (매일 자동 업데이트)
  - 2년 이내 데이터 자동 유지

✅ 통계적 신뢰도:
  - 신뢰 가능 패턴 (20경기+): 21.8%
  - 양호 패턴 (10-19경기): 32.1%
  - 전체 54%가 통계적으로 신뢰 가능

핵심 파일:
----------
daily_betting_report.sh              # 마스터 실행 스크립트
fetch_tomorrow_games.py              # 내일 경기 스케줄
fetch_game_preview.py                # ESPN 프리뷰
calculate_game_context.py            # 컨텍스트 계산 (휴식일, 백투백)
context_based_analysis.py            # 역사적 패턴 기반 예측
recent_form_analysis.py              # 최근 트렌드 분석
analyze_with_preview.py              # 통합 보고서
update_yesterday_games.py            # 일일 업데이트
migrate_clean.py                     # Neo4j 임포트
player_impact_analysis.py            # 선수 영향 분석 (proof of concept)

Neo4j 스키마:
-------------
(:GameState) - 팀 수준 경기 데이터
  - game_id, date, season
  - home_team, away_team, home_score, away_score, home_win
  - home_rest_days, away_rest_days

(:Team) - 팀 노드
(:Player) - 선수 노드 (이름만)
(:Referee) - 심판 노드
(:Venue) - 경기장 노드

한계사항:
----------
❌ 선수별 box score 없음 (팀 수준만)
❌ Advanced stats 없음 (eFG%, offensive rating 등)
❌ 선수 IN/OUT 효과는 날짜 기반 proxy만 가능

예측 정확도 (예상):
------------------
역사적 패턴만: 55-60%
최신 트렌드만: 60-65%
통합 시스템: 65-70%
높은 신뢰도 경기 (모멘텀 차 30+): 75-80%
