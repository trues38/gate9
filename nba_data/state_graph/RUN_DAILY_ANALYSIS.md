# 매일 경기 분석 실행 가이드

**목표**: 내일 경기에 대한 프리뷰 + 패턴 분석 통합 보고서 생성

---

## 🚀 빠른 실행 (3분)

```bash
# 1단계: 내일 경기 스케줄 가져오기
python3 fetch_tomorrow_games.py

# 2단계: ESPN 프리뷰 정보 수집
python3 fetch_game_preview.py

# 3단계: 통합 분석 보고서 생성
python3 analyze_with_preview.py
```

**결과**: `enhanced_analysis_YYYYMMDD_HHMM.txt` 파일 생성

---

## 📋 단계별 설명

### Step 1: 내일 경기 스케줄 (30초)

```bash
python3 fetch_tomorrow_games.py
```

**출력**:
- 내일 예정된 경기 목록
- 팀, 시간, 경기장 정보
- `tomorrow_games.json` 저장

**예시**:
```
📅 내일 NBA 경기 스케줄 (9경기)
1. 00:00 - MIA @ ATL
2. 00:00 - CHA @ ORL
...
```

---

### Step 2: ESPN 프리뷰 정보 (1분)

```bash
python3 fetch_game_preview.py
```

**수집 정보**:
- ✅ 배당 정보 (스프레드, 오버/언더, 머니라인)
- ✅ ESPN 승률 예측
- ✅ 부상자 명단
- ⚠️  심판 정보 (경기 전 공개 시)

**출력**:
- 각 경기별 프리뷰 상세
- `tomorrow_previews.json` 저장

**예시**:
```
📋 프리뷰: MIA @ ATL
💰 배당 정보:
  스프레드: -3.5
  오버/언더: 228.5
  홈 머니라인: -150

🏥 부상자 명단:
  [MIA] Jimmy Butler - Questionable: ankle

⚠️  심판 정보 아직 공개 안됨
```

---

### Step 3: 통합 분석 보고서 (1분)

```bash
python3 analyze_with_preview.py
```

**포함 내용**:
1. **ESPN 프리뷰**
   - 배당 정보
   - 승률 예측
   - 부상자 명단
   - 심판 정보 (공개 시)

2. **패턴 분석** (과거 927게임 기반)
   - 홈/원정 전적 및 평균 득점차
   - 최근 10경기 폼
   - 백투백 경기 성적
   - 휴식일별 승률 패턴

3. **핵심 인사이트**
   - 최근 폼 비교
   - 홈/원정 강점 분석
   - 부상자 영향 평가
   - 심판 효과 (공개 시)
   - 배당 vs 실제 데이터 비교

**출력 예시**:
```
==================================================================================
📊 경기 분석: BOS @ IND
==================================================================================

----------------------------------------------------------------------------------
💰 ESPN 프리뷰
----------------------------------------------------------------------------------
배당:
  스프레드: -8.5 (홈팀 기준)
  오버/언더: 235.5

ESPN 승률 예측:
  IND: 35.2% (예상 112점)
  BOS: 64.8% (예상 121점)

🏥 부상자 명단:
  🔴 [IND] Tyrese Haliburton - Out: hamstring

⚠️  심판 정보 미공개

----------------------------------------------------------------------------------
📈 패턴 분석 (과거 927게임 기반)
----------------------------------------------------------------------------------
🏠 IND (Indiana Pacers):
  홈 전적: 13-17 (43.3%, 평균 +0.0점)
  최근 10경기: 2-8 (평균 -8.3점)
  백투백: 1-4 (20.0%, 평균 -9.2점)

✈️  BOS (Boston Celtics):
  원정 전적: 19-9 (67.9%, 평균 +4.8점)
  최근 10경기: 7-3 (평균 +6.2점)

----------------------------------------------------------------------------------
💡 핵심 인사이트
----------------------------------------------------------------------------------
  ⚠️  IND 최근 부진 (2-8, 20.0%)
  ✅ BOS 최근 강한 폼 (7-3, 70.0%)
  ✈️  BOS 강한 원정팀 (67.9% 원정 승률)
  🏥 IND 핵심 선수 부상 (Haliburton) - 전력 약화
  📈 ESPN 예측: BOS 압도적 우세 (64.8%)
  💰 배당: BOS 대승 예상 (스프레드 8.5)

==================================================================================
```

## ⏰ 심판 정보 확인 타이밍

심판 정보는 **경기 시작 2-6시간 전**에 공개되는 경우가 많습니다.

### 심판 정보 확인하기

```bash
python3 check_referee_timing.py
```

**출력**:
```
============================================================================
심판 정보 확인 - 2025-12-25 18:00:00
============================================================================
❌ MIA @ ATL (00:00) - 심판 정보 없음
❌ CHA @ ORL (00:00) - 심판 정보 없음
...

총 9경기 중 0경기 심판 정보 공개
공개율: 0.0%

💡 권장: 경기 시작 4-6시간 전에 다시 확인하세요
```

### 권장 실행 시간

| 경기 시간 | 1차 실행 (프리뷰) | 2차 실행 (심판 포함) |
|----------|-----------------|-------------------|
| 19:00 경기 | 오전 9:00 | 오후 15:00 |
| 00:00 경기 | 오후 14:00 | 오후 20:00 |
| 03:00 경기 | 오후 17:00 | 오후 23:00 |

## 💡 팁

### 1. 심판 정보가 없을 때
- 경기 시작 4-6시간 전에 다시 실행
- Step 2, 3만 재실행하면 됨 (Step 1은 스킵)

### 2. 여러 경기 중 특정 경기만 분석
- `tomorrow_games.json`에서 원하는 경기만 남기고 삭제
- Step 3 재실행

### 3. 과거 경기 보고서 보관
- `enhanced_analysis_*.txt` 파일은 자동으로 타임스탬프 포함
- 날짜별로 보관 가능

---

## ❓ 문제 해결

### "tomorrow_games.json이 없습니다"
→ Step 1부터 다시 실행

### "프리뷰 정보가 없습니다"
→ Step 2 실행 필요

### Neo4j 연결 실패
→ Neo4j 컨테이너 확인: `docker ps`
→ 재시작: `docker restart neo4j-nba`
