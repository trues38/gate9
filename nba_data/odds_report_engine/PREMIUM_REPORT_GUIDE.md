## 💡 고급 사용법

### 1. Daily Batch Processing

```bash
# 오늘 모든 경기에 대해 프리미엄 리포트 생성
for game in $(cat todays_games.txt); do
    HOME=$(echo $game | cut -d'@' -f2)
    AWAY=$(echo $game | cut -d'@' -f1)
    ./generate_premium_report.sh $HOME $AWAY
    sleep 5  # API rate limit 고려
done
```

### 2. JSON 컨텍스트 재사용

```bash

python3 ai_betting_council.py --context-file $CONTEXT_FILE
```

### 3. 성과 추적

```bash

grep -r "\"score\":" /Users/js/g9/nba_data/odds_reports/*.json

# ROI 계산 (실제 결과와 비교)

import json
import glob

for r in reports:
    with open(r) as f:
        data = json.load(f)
        score = data['consensus']['score']
        rec = data['consensus']['recommendation']
        print(f"{r}: {score} → {rec}")
EOF
```
