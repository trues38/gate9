## 🛠️ 수정이 필요한 경우

### 패턴 1: H2H 데이터 불일치

**검증 결과:**
```

⚠️ Neo4j: 7-2
```

**당신의 판단:**
```
"ESPN은 이번 시즌만 (0-1)
Neo4j는 전체 시즌 (7-2)
보고서는 최근 5경기 (5-0)

→ 이번 시즌 기준으로 통일"
```

**수정 프롬프트:**
```bash
> "SAC @ LAC 보고서 수정해줘.
   H2H를 '이번 시즌: 0-1'로 변경하고
   '과거 포함 최근 5경기: 5-0'을 참고로 추가"
```

```

### Tip 2: 80점대는 빠른 수정
```
88점 보고서 → 1-2개 경고만 있음
→ 3분 수정 → 95점
→ 수정하면 더 좋음
