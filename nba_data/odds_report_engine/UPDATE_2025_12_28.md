### 2. 백업 모델 시스템 추가 ⭐

각 분석가에게 3개의 무료 백업 모델 추가:

```python
"backup_models": [
    "xiaomi/mimo-v2-flash:free",       # Xiaomi (⭐⭐⭐⭐)
    "tng/deepseek-r1t2-chimera:free",  # TNG (⭐⭐⭐)
    "zai/glm-4.5-air:free"             # Z.AI (⭐⭐⭐)
]
```

**동작 원리**:
1. 메인 모델 호출
2. 실패 시 → 백업 모델 1 시도
3. 실패 시 → 백업 모델 2 시도
4. 실패 시 → 백업 모델 3 시도
5. 모두 실패 시 → 에러 반환

### 3. Fallback 로직 구현

`call_analyst()` 메서드에 자동 Fallback 추가:

```python
def call_analyst(self, analyst_id: str, user_prompt: str) -> Dict:
    # 시도할 모델 리스트
    models_to_try = [analyst['model']] + analyst.get('backup_models', [])

    for idx, model in enumerate(models_to_try):
        try:
            # 모델 호출 시도
            ...
        except Exception as e:
            # 실패 시 다음 모델로
            continue

    # 모든 모델 실패
    return {"success": False, "error": "All models failed"}
```
