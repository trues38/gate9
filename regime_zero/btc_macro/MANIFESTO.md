# BTC Macro Engine - MANIFESTO

> **"연 10회의 확실한 기회. 그 외엔 침묵."**

---

## 1. 정체성

BTC Macro는 **경제 레짐 기반 Law 실행 엔진**이다.

전통적으로 알려진 경제 상식들 - "금리가 오르면 주식이 떨어진다", "VIX가 튀면 안전자산으로 간다" - 이런 것들을 **실제 데이터로 백테스트**해서:

- **진짜 작동하는 것** → Law로 등록
- **그냥 썰인 것** → 폐기

이렇게 걸러낸 **"투자 답지"**다.

---

## 2. 핵심 철학

### 2.1 희소성이 가치다
- 매일 시그널 주는 시스템 ❌
- **연 10회 내외**의 고확률 기회만 포착
- "기회가 없으면 아무것도 안 한다"가 정답

### 2.2 검증 없으면 폐기
- In-Sample 좋아도 OOS(Out-of-Sample) 실패하면 **즉시 폐기**
- p-value < 0.05 미만만 Law로 인정
- 감으로 만든 전략은 존재하지 않는다

### 2.3 매년 보정은 필수
- 시장 구조는 변한다 (예: 2024 BTC ETF 출시)
- **매년 1월** 전년도 데이터로 Law 재검증
- 성능 저하된 Law는 Deprecated 처리

## 5. 알림 시스템

### 알림 발생 조건
```python
def should_alert(law_name, signal_strength):
    """
    알림은 Law 조건 충족 시에만 발생
    - 일일 리포트 ❌
    - 주간 요약 ❌
    - Law 트리거 시에만 ✅
    """
    if law_is_active(law_name) and signal_strength >= THRESHOLD:
        return True
    return False
```

### 알림 형식
```
🔔 [BTC MACRO] ETF_ACCUMULATION 트리거

조건: IBIT Vol 1.47x, BTC -3.2%
액션: Long BTC
목표: +7% / 손절: -5% / 기한: 10일

기대 승률: 73% (Historical)
마지막 발동: 2024-11-15 (성공 +5.2%)
```

## 6. 연간 보정 프로토콜

### 매년 1월 첫째 주 실행
1. **전년도 시그널 수집** - 모든 Law 발동 기록
2. **OOS 재검증** - 새 데이터로 승률 계산
3. **Law 상태 업데이트**
   - OOS > 65%: Active 유지
   - OOS 50-65%: Warning (모니터링)
   - OOS < 50%: Deprecated
4. **새 가설 탐색** - 시장 구조 변화 반영

## 8. 절대 금지 사항

1. **Law 임의 추가 금지** - 백테스트 검증 없이 "이거 될 것 같은데" 금지
2. **희소성 훼손 금지** - "자주 알림 가게" 임계값 낮추기 금지
3. **손절 무시 금지** - "조금만 더 기다리면" 금지
4. **과거 조작 금지** - 백테스트 결과 체리피킹 금지
