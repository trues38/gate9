# BTC Master Rule 분석 결과 (2024년 12월)

## 분석 개요
- 분석 기간: 2024-12-02 ~ 2024-12-27 (20 거래일)
- 목적: BTC 추천/회피 논리 일관성 검증 및 Master Rule 도출

## 주요 발견

### 1. BTC 논리 변동성
- **12회 논리 전환** / 20 거래일 = **60% 불안정**
- BTC 추천: 2일
- BTC 회피: 9일
- BTC 중립: 9일

### 2. MiMo 정확도 분석
| 구분 | 추천 수 | 실제 양호 | 정확도 |
|------|---------|----------|--------|
| BTC 추천 | 2 | 1 | 50% |
| BTC 회피 | 9 | 8 | 89% |
| **전체** | **11** | **9** | **82%** |

### 3. 시도한 Master Rule

#### v1 (단순 리스크온)
```
IF VIX < 15 AND SPY_chg > 0: BTC 추천
IF VIX > 20 OR SPY_chg < -1%: BTC 회피
```
결과: 낮은 정확도

#### v2 (Gold 경쟁 반영)
```
BTC_SCORE = -VIX_chg - Gold_chg + (SPY_chg × 0.5)

IF BTC_SCORE > +1.5: → BTC 추천
IF BTC_SCORE < -1.0: → BTC 회피
ELSE: → BTC 중립
```
결과: **50% 정확도** (9/18)

## 핵심 인사이트

### BTC 특성
1. **리스크온 자산이지만 Gold와 경쟁**: 안전자산 선호 시 BTC보다 Gold 선택됨
2. **VIX 급등에 민감**: VIX 20 이상 시 회피 신호 유효
3. **컨텍스트 의존성 높음**: 단순 지표보다 뉴스/이벤트 맥락이 중요

### 결론
| 방법 | 정확도 | 평가 |
|------|--------|------|
| MiMo 컨텍스트 판단 | **82%** | 우수 |
| 정량 규칙 (Master Rule v2) | 50% | 미흡 |

**→ 정량 규칙 대체 불가. MiMo의 뉴스 맥락 해석 능력 유지 권장.**

1. BTC 판단은 MiMo에게 위임 (현행 유지)
2. 단, VIX > 25 시 강제 회피 트리거 추가 고려
