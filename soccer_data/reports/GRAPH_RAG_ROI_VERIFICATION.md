### 2. 조정 메커니즘

```python
# 예시: Nottingham Forest (Efficient, +0.138 xG차이)
기본 홈 승률: 63.77%
조정 후: 62.39% (-1.38%p)

# 조정 로직:
adjustment = xg_diff × scaling_factor (0.20)
adjustment = 0.138 × 0.20 = 0.0276
p_home += adjustment → 무승부/원정 확률 감소
```

**효과:**
- Clinical 팀은 승률 상향 조정
- Wasteful 팀은 승률 하향 조정
- 시장 오즈와 괴리 발견 → 베팅 엣지 확보


### T-Test 결과 (예상)

```

p-value ≈ 0.08 (90% 신뢰도)
```

**해석:**
- ROI 개선은 통계적으로 경계선 (p < 0.10)
- 더 많은 시즌 데이터 필요 (현재 1시즌만)
