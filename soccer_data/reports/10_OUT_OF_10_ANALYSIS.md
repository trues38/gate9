**날짜**: 2025-12-29
**질문**: 10/10 수준이 되려면 실시간성이 필요한가? 정량 데이터는 충분한가?

## 핵심 답변

### Q1: 실시간성이 필요한가?

**답변: ❌ 아니요, 필수가 아닙니다.**

**이유:**

1. **NBA 분석도 실시간이 아님**
   - NBA 프리게임 분석: 경기 시작 **1-2시간 전** 최종 예측
   - 라인업 확정: 경기 시작 **30분 전**
   - 베팅 마감: 경기 시작 직전

2. **우리 목적도 프리게임 예측**
   - 베팅은 경기 시작 전에 마감
   - 경기 전날 저녁 ~ 당일 오전 데이터면 충분
   - 인게임(라이브) 베팅은 별도 영역

3. **필요한 "신선도"**
   ```
   실시간 (초단위):        ❌ 불필요
   당일 (시간 단위):       ⚠️  인게임 베팅용
   경기 전날 (일 단위):    ✅ 충분 (우리 목적)
   주간 업데이트:          ⚠️  너무 느림
   ```

**결론**: 경기 시작 **12-24시간 전** 데이터만 있으면 10/10 가능

## 10/10을 위해 정말 필요한 것

### 1. 부상/출전 가능 정보 (팩트 데이터)

**타입**: 정량 데이터 (Binary: 출전 O/X)

**필요한 형태:**
```json
{
  "player": "Mohamed Salah",
  "status": "OUT",           // OUT, DOUBTFUL, PROBABLE, ACTIVE
  "injury": "hamstring",
  "expected_return": "2024-11-15",
  "impact": "HIGH"           // 주전=HIGH, 교체=MEDIUM, 벤치=LOW
}
```

**수집 방법:**
- TransferMarkt (무료, 업데이트 빠름)
- ESPN (무료, 영어권 리그)
- 공식 클럽 발표

**업데이트 빈도:**
- 일 1회 (저녁 9시) ✅ 충분
- 경기 당일 오전 추가 체크 (라인업 발표 전)

**실시간 필요성:**
- ❌ 불필요
- 경기 전날 저녁 데이터면 충분
- 긴급 부상은 희귀 (전체의 <5%)

---

### 2. 예상 선발 라인업 (팩트 데이터)

**타입**: 정량 데이터 (11명 명단)

**필요한 형태:**
```json
{
  "match_id": "12345",
  "home_lineup": ["Player1", "Player2", ...],  // 11명
  "away_lineup": ["Player11", "Player12", ...],
  "confidence": 0.85,         // 예측 확신도
  "source": "lineup_predictor"
}
```

**수집 방법:**
- 과거 선발 패턴 학습 (우리 데이터로 가능!)
- Lineup11.com (무료 예측)
- 공식 발표 (경기 30분-1시간 전)

**업데이트 빈도:**
- 경기 전날: 예측 라인업
- 경기 당일 오전: 업데이트된 예측
- 경기 30분 전: 공식 라인업 (최종)

**실시간 필요성:**
- ❌ 불필요 (경기 시작 1시간 전까지만)
- 베팅 마감 전에만 확인하면 됨

---

### 3. 감독 전술 선호도 (정성 데이터)

**타입**: 정성 데이터 (하지만 구조화 가능)

**필요한 형태:**
```json
{
  "manager": "Pep Guardiola",
  "preferred_formation": "4-3-3",
  "alternative_formations": ["3-2-4-1", "4-2-3-1"],

  "home_away_difference": 0.05,  // 홈/원정 전술 차이
```

**수집 방법:**
- 수동 큐레이션 (한번 구축하면 유지만)
- 전술 기사 분석 (Spielverlagerung 등)

**업데이트 빈도:**
- 시즌 초: 전체 검토
- 월 1회: 변화 모니터링
- 실시간 불필요 ✅
